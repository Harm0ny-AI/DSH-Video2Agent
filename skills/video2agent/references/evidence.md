# Evidence rules

- Every answer that uses video content should carry a timecode.
- Use the tool's timecode; never invent or round a timestamp.
- Cite as: 《title》 HH:MM:SS.
- Keep evidence_id when writing structured notes.
- Label the source: transcript / OCR / visual inference.
- If confidence is low or warnings exist, say so.
- If audio or OCR is missing, say what the conclusion is based on.
- Quotes from low-confidence ASR are "转写大意", not exact quotes.
- A citation proves that a source exists; it does not prove that the claim is
  correct. Important claims still need review.
